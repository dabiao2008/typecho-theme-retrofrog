# Typecho Theme: RetroFrog (铁皮发条蛙) 🐸

一款专为 Typecho 设计的复古老玩具风格主题，灵感来源于经典的“绿皮发条跳跳蛙”。

本项目最初由 [finch-xu](https://github.com/finch-xu) 设计的 Hexo 优秀主题 [hexo-theme-warmpaper](https://github.com/finch-xu/hexo-theme-warmpaper) 移植而来，并针对“复古玩具”这一核心理念进行了深度的视觉重构与色彩定制。

## ✨ 主题特色

* 🎨 **复古视觉体验**：采用铁皮玩具经典的“珐琅墨绿”与“复古橘黄”作为核心交互色，搭配老式包装纸风格的单向斜线背景，拉满年代感。
* 📱 **响应式设计**：无论是桌面端、平板还是手机，都能获得优雅的阅读体验。
* 🌗 **深色模式 (Dark Mode)**：支持跟随操作系统自动切换深色模式，夜晚阅读同样舒适。
* ⚡ **轻量与纯粹**：去除冗余功能，专注于图文内容的展示，非常适合用于介绍老物件、复古玩具或个人随笔。
* 🛠️ **原生评论支持**：完美适配 Typecho 原生评论系统。

## 📦 安装方法

1. 点击本仓库右上角的 `Code` -> `Download ZIP` 下载主题压缩包。
2. 将下载的压缩包解压，并将解压后的文件夹重命名为 `retrofrog`。
3. 将 `retrofrog` 文件夹上传至你的 Typecho 站点目录：`/usr/themes/`。
4. 登录 Typecho 后台，在 **控制台** -> **外观** 中找到 `RetroFrog`，点击 **启用**。
